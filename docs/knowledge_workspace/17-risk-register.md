# 17 - Risk Register & Mitigation Strategies

| ID | Risk Description | Severity | Likelihood | Mitigation Strategy | Residual Risk |
|---|---|---|---|---|---|
| **R-01** | **Data Loss During Autosave**: Network disconnect or tab closure while editing could cause unpersisted edits to be lost. | High | Medium | 1. Local state buffer retains unsaved content in memory and `localStorage`.<br>2. Warn on `beforeunload` if `isDirty` is true.<br>3. Visual status indicator clearly shows `Offline / Save Failed` with retry button.<br>4. Revisions created on every save for version recovery. | Low |
| **R-02** | **Broken Legacy Routes / Bookmarks**: Users accessing old URLs (`/app/docs/spaces/[spaceId]/[pageId]`) might experience 404s or broken links. | High | Low | 1. Legacy routes preserved and automatically wrap the new workspace shell with the target page opened in the active tab.<br>2. Public documentation routes (`/docs/[category]/[slug]`) remain unchanged.<br>3. Slug-to-UUID resolver ensures bookmarked URLs continue resolving. | Negligible |
| **R-03** | **Search Performance Degradation**: As document and source chunk volume grows, search latency exceeds the 200ms budget. | Medium | Medium | 1. PostgreSQL GIN index on stored `search_vector`.<br>2. Exact title and slug prefix matching handled in Layer 1 before full-text queries.<br>3. Result set hard limit of 30 items.<br>4. Debounced user input (250ms). | Low |
| **R-04** | **AI Context Data Leakage**: Private or restricted documents inadvertently retrieved and exposed to unauthorized users via AI chat or search. | Critical | Low | 1. Pre-retrieval authorization gate: queries enforce `docs.permissions` and space visibility directly in SQL before candidate retrieval.<br>2. AI context builder verifies user access on every item before prompt construction.<br>3. Integration and E2E security tests continuously assert privacy boundaries. | Very Low |
| **R-05** | **Large Tree DOM Explosion**: Workspaces with thousands of pages experience frame drops and UI freezing during tree navigation. | Medium | Medium | 1. Collapsible lazy-loaded space nodes.<br>2. Virtualized list rendering for tree containers exceeding 300 nodes.<br>3. Component memoization preventing unnecessary re-renders when expanding adjacent nodes. | Low |
| **R-06** | **LLM Hallucination / Citation Drift**: Model generates factual claims without supporting context or references invalid source chunks. | Medium | Medium | 1. System prompt strictly penalizes answering without provided context.<br>2. Prompt instructs the model to state "The provided sources do not contain this information" if missing.<br>3. Citation parser validates that bracketed numbers correspond to real retrieved chunk IDs. | Low |
| **R-07** | **Graph Render Freezing**: Large knowledge graphs (>500 nodes) freezing the browser main thread during force-directed layout computation. | Medium | Low | 1. Canvas-based rendering instead of React DOM nodes.<br>2. WebWorker force simulation calculation where applicable.<br>3. Default to Local Graph (depth=1) with explicit user toggle for Global Graph.<br>4. Clustering nodes by space/community to limit visible edges. | Low |
